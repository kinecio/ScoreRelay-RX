Connection mode

Connect through the ScoreRelay cloud using an access token from your ScoreRelay cloud portal (Live Data tab). The server is fixed — nothing to configure here. Cloud connectivity is rolling out; if your account doesn't have it yet, this may not connect — use Local device mode instead.

Connect straight to a ScoreRelay device on your network. Host is the device's IP address; the API token is shown once under Security on the device's settings page.

Connect a ScoreRelay device with a USB cable. Works even when the device has no Wi-Fi or network at all. The connection runs inside this app, so it stays up without keeping this page open.

Connect to a ScoreRelay device wirelessly over Bluetooth — no network needed. The first time, your computer has to be paired with the device using the 6-digit passkey from the device's label or your ScoreRelay portal. macOS asks for it automatically when you connect; on Windows, pair the device in your system Bluetooth settings first. Then enter the device's admin password. The connection runs inside this app, so it stays up without this page.
