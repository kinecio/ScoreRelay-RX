First launch

These apps are not signed with a paid developer certificate, so your computer will warn you the first time. That is expected.

macOS

  1. Open the .dmg and drag ScoreRelay-RX to Applications.
  2. Right-click the app and choose Open the first time.
  3. If you use Bluetooth, choose Allow when macOS asks, then quit and reopen the app once so it takes effect.

Windows

  1. Run the setup file.
  2. If SmartScreen says it protected your PC, choose More info → Run anyway.
